# 食刻正式版 PWA

这是从已确认的 UI 原型迁移而来的正式 React + TypeScript 工程，当前版本为 v0.9。

## 技术栈

- React + TypeScript + Vite
- Dexie + IndexedDB 本地数据库
- vite-plugin-pwa
- Vitest

## 本地运行

Windows 用户可以直接双击项目根目录中的 `start-shike.bat`。首次启动会自动安装依赖，完成后浏览器将自动打开食刻。弹出的“食刻服务”窗口需要在使用期间保持开启；关闭它即可停止运行。

## 更新版本

开发阶段收到新版本 ZIP 后：

1. 先关闭旧的“Shike Server”窗口。
2. 把新 ZIP 解压并覆盖到原来的食刻文件夹，或者解压到一个新文件夹。
3. 双击新版 `start-shike.bat`。

BAT 会识别版本变化并在需要时更新运行组件。同一版本的日常使用不需要重复解压或安装。只要继续使用同一浏览器和 `http://127.0.0.1:5173`，IndexedDB 中的饮食数据不会因为覆盖程序文件而消失。正式稳定版计划部署到固定网址，之后更新不再需要手动解压。

也可以手动运行：

```powershell
npm install
npm run dev
```

## 检查与构建

```powershell
npm test
npm run build
```

## 当前已完成

- 正式的 Food、MealEntry、DailyGoal、WaterEntry 和 Settings 数据模型
- 饮食记录保存营养快照，食品资料以后改变也不会影响历史数据
- kcal/kJ 精确换算与份、包、克三种数量输入
- 今日目标、剩余能量、营养汇总、钠和饮水
- 食品库选择与记录弹层
- 最近 14 天日期入口
- 能量、蛋白质、碳水、脂肪和饮水目标设置
- 每日目标按生效日期保存历史版本，修改新目标不会改写过去日期
- 日历详情显示当日采用的目标，能量趋势图同时展示实际值与历史目标线
- 设置页提供 iPhone Safari“添加到主屏幕”引导，并显示安全连接、网络和运行模式
- PWA 清单补齐应用标识、作用域、竖屏方向和 iOS 主屏幕名称
- 从本地地址迁移到线上地址前提供明确的 JSON 备份与恢复提醒
- 记录食用量时可直接输入准确克数，并以 1g 按钮微调
- 新增食品时可创建自定义分类，分类会长期保留并加入食品库筛选
- 修复 iPhone 聚焦输入框后页面自动放大，以及每日目标输入框重叠
- 拍照或从相册选择营养成分表，在设备本地 OCR 后生成可编辑草稿
- OCR 结果不会自动入库，必须在新增食品页人工核对后保存
- 标准月历网格、日期标记和当天饮食详情
- 日历中的 7 天 / 30 天能量与三大营养素趋势图
- 鼠尾草、天空蓝、暖杏、薰衣草和石墨五套 iOS 风格主题
- 常见营养素数据字段，以及首页 1–6 张营养卡片的自选展示
- 对标签未提供的营养素显示“未记录”，不把未知值误当成 0
- 手动新增和编辑食品，支持 kcal/kJ、份量、包装重量与完整营养素
- 食品库搜索，以及方便速食、主食、肉蛋奶、饮品、零食和其他分类筛选
- 安全移出食品库；历史饮食记录使用营养快照，不会随食品资料修改或移出而改变
- 从“今天”或“日历”打开饮食记录，修改日期、时间、输入方式和食用数量
- 修改记录时按原始营养快照同比重算，不套用后来修改过的食品标签
- 删除前二次确认，修改和删除后提供 5 秒撤销入口
- 食品库支持最近使用、最近编辑和名称排序
- JSON 全量备份与恢复，恢复前检查文件、展示数据数量并要求确认覆盖
- 设置页显示食品、饮食记录、饮水记录数量和最近备份时间
- IndexedDB 持久化与 PWA 离线构建
- 营养计算自动化测试
